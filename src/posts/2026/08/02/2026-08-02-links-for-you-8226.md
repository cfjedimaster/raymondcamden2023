## Web browsing on your gaming console

First up is a great post by Vale detailing the capabilities and [history of web browsers on game consoles](https://vale.rocks/posts/game-console-browsers). I've been playing on consoles since the *very* beginning and a lot of this was still new and surprising to me. Honestly I can't imagine surfing any web page on a browser now. I think the last time I did was on my XBox so I could find a cool background picture.
